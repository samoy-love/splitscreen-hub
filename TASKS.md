Две задачи, обе про данные. Они не пересекаются с кодом приложения и друг с
другом: B пересобирает `catalog.db`, C пишет в отдельный `ratings.db`.
`build_db.py` подмешивает `translations.db` и `ratings.db`, если они есть, а
приложение читает их через `COALESCE` — каталог остаётся рабочим на любой
стадии: у игры без перевода показывается английский текст, у игры без оценки её
просто нет.

| Задача | Что трогает | Зачем |

| B. 32 игры | `make_overrides.py`, `catalog.db` | остались без числа игроков |
| C. Оценки (Steam) | `ratings.db` | колонка `rating` пустует; ключи не нужны |

`.nro` — иначе в romfs уедет прежний каталог.

Сделанное и удалённое из этого файла: перевод каталога (`translations.db`),

## B. Дописать 32 игры без числа игроков

```
В каталоге 32 игры имеют метку eShop «Play together on one console», но число
игроков на одном экране у них неизвестно, поэтому в базу они не попадают.

Посмотри список:

  python -c "import json; d=json.load(open('local_multiplayer.json',encoding='utf-8')); o=json.load(open('overrides.json',encoding='utf-8')); print('\n'.join(sorted(r['title'].strip() for r in d if not r['same_screen_max'] and not (r['nsuid'] or '').startswith('7007') and r['nsuid'] not in o)))"

По каждой найди, сколько игроков поддерживается на ОДНОМ экране именно в версии
для Nintendo Switch. Это важно: у Stardew Valley на оригинальном Switch
сплитскрин на двоих, а четверо — только в издании для Switch 2; у Terraria
локально двое, а не восемь.

Источники по убыванию доверия:
1. Описание игры от издателя — оно уже лежит в local_multiplayer.json в полях
   headline и description. Это самый надёжный и бесплатный источник, начни с
   него: у многих игр число названо прямо («a 2-player cooperative puzzle
   platformer», «up to 5 players per turns»).
2. Официальная страница издателя или его поддержки.
3. co-optimus.com — там данные по каждой платформе отдельно.

Не используй searching.nintendo-europe.com: он смешивает локальный режим с
онлайном и врёт (у Voice of Cards показывает 4 игрока, хотя игра одиночная).

Результат добавь в make_overrides.py: в словарь VERIFIED, если мультиплеер
подтвердился, или в WRONGLY_TAGGED с причиной, если метка eShop неверна и
мультиплеера на одном экране нет. По каждой записи указывай источник — так же,
как это сделано у существующих. Игры, по которым надёжного ответа нет, оставь
как есть: лучше не показать игру, чем соврать про число игроков.

Затем:
  python make_overrides.py && python build_db.py && python download_art.py && python verify_db.py
  python make_ship_data.py

Добавь в verify_db.py проверки на несколько новых игр и сообщи, сколько удалось
подтвердить, сколько исключено и сколько осталось без ответа.
```

## C. Оценки игр

Промт вынесен отдельно: **`PROMPT_C_RATINGS.md`**. Источник — отзывы Steam, а не
IGDB: замерено, что 37% каталога имеют там 50+ отзывов, а выборки на порядки
больше критических. Ключи и регистрации не нужны.

Учтите: приложение оценки пока нигде не показывает. `build_db.py` их
подмешивает, но в `Game`, `catalog.bin` и карточке поля `rating` нет — вывод в
интерфейс придётся сделать вместе с задачей.
