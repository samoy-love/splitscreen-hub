# Что осталось и промты для параллельных сессий

Все пять задач можно запускать одновременно: они не трогают одни и те же файлы.
Это было отдельно подготовлено — `build_db.py` больше не уничтожает чужую работу,
а подмешивает `translations.db` и `ratings.db`, если они есть. Приложение читает
их через `COALESCE`, поэтому каталог остаётся рабочим на любой стадии: у
непереведённой игры показывается английский текст, у игры без оценки её просто
нет.

| Задача | Что трогает | Зачем |
|---|---|---|
| A. Перевод | `translations.db` | 3.7 млн знаков описаний по-английски |
| B. 32 игры | `make_overrides.py`, `catalog.db` | остались без числа игроков |
| C. Оценки (Steam) | `ratings.db` | колонка `rating` пустует; ключи не нужны |
| D. Трейлеры | `app/source/ui/`, `app/CMakeLists.txt` | в карточке только скриншоты |
| E. Иконка | `app/resources/icon.jpg` | сейчас стоит демо-иконка borealis |

Единственное пересечение: **B пересобирает `catalog.db`**, поэтому после её
завершения нужно один раз выполнить `cp catalog.db app/resources/catalog.db` и
пересобрать `.nro`. Остальные задачи к этому файлу не прикасаются.

Задача A — самая длинная (несколько миллионов знаков), E — самая короткая.

## A. Перевод каталога на русский

Промт лежит отдельно: **`TRANSLATE_PROMPT.md`**. Там же замеры вёрстки, из
которых выведены лимиты длины.

Одна поправка к нему: писать не в `catalog.db`, а в отдельный файл

## B. Дописать 32 игры без числа игроков

```
В каталоге 32 игры имеют метку eShop «Play together on one console», но число
игроков на одном экране у них неизвестно, поэтому в базу они не попадают.

Посмотри список:

  python -c "import json; d=json.load(open('local_multiplayer.json',encoding='utf-8')); o=json.load(open('overrides.json',encoding='utf-8')); print('\n'.join(sorted(r['title'].strip() for r in d if not r['same_screen_max'] and not (r['nsuid'] or '').startswith('7007') and r['nsuid'] not in o)))"

По каждой найди, сколько игроков поддерживается на ОДНОМ экране именно в версии
для Nintendo Switch. Это важно: у Stardew Valley на оригинальном Switch
сплитскрин на двоих, а четверо — только в издании для Switch 2; у Terraria
локально двое, а не восемь.

Источники по убыванию доверия:
1. Описание игры от издателя — оно уже лежит в local_multiplayer.json в полях
   headline и description. Это самый надёжный и бесплатный источник, начни с
   него: у многих игр число названо прямо («a 2-player cooperative puzzle
   platformer», «up to 5 players per turns»).
2. Официальная страница издателя или его поддержки.
3. co-optimus.com — там данные по каждой платформе отдельно.

Не используй searching.nintendo-europe.com: он смешивает локальный режим с
онлайном и врёт (у Voice of Cards показывает 4 игрока, хотя игра одиночная).

Результат добавь в make_overrides.py: в словарь VERIFIED, если мультиплеер
подтвердился, или в WRONGLY_TAGGED с причиной, если метка eShop неверна и
мультиплеера на одном экране нет. По каждой записи указывай источник — так же,
как это сделано у существующих. Игры, по которым надёжного ответа нет, оставь
как есть: лучше не показать игру, чем соврать про число игроков.

Затем:
  python make_overrides.py && python build_db.py && python download_art.py && python verify_db.py
  python make_ship_db.py

Добавь в verify_db.py проверки на несколько новых игр и сообщи, сколько удалось
подтвердить, сколько исключено и сколько осталось без ответа.
```

## D. Трейлеры в карточке игры

Промт вынесен отдельно: **`PROMPT_D_TRAILERS.md`**. Краткая версия:

```
В карточке игры сейчас показываются только скриншоты. Нужно добавить
проигрывание трейлеров: адреса mp4 уже лежат в таблице media каталога с
kind='video' (у 59% игр).

Свой плеер не пиши. Используй libmpv: ей отдаётся URL и OpenGL-контекст, а она
сама делает демукс, декод, ресемпл и синхронизацию звука; управление — вызовы
mpv_command для паузы и перемотки. Borealis рисует через OpenGL, поэтому mpv
рендерит в FBO, который показывается текстурой.

Под Switch libmpv собирают: посмотри рецепты NXMP (github.com/proconsule/nxmp)
и SwitchWave — там mpv с FFmpeg и аппаратным декодированием через Tegra NVDEC.
Пакета switch-mpv в pacman нет, придётся собирать из исходников; switch-ffmpeg
там есть.

Если сборка libmpv окажется неподъёмной, запасной путь — switch-ffmpeg из
pacman и минимальный проигрыватель поверх него. В этом случае честно скажи, что
выбран запасной путь и почему.

Что сделать в приложении:
- кнопка воспроизведения поверх первого скриншота, если у игры есть видео;
- полноэкранный просмотр по нажатию, выход по B;
- пауза по A, перемотка стиком;
- загрузка не должна блокировать интерфейс, как это уже сделано в
  source/ui/remote_image.cpp — посмотри, как там устроена связка brls::async и
  brls::sync и флаг alive для случая, когда пользователь ушёл раньше.

Собирается так (Ninja обязательно, Makefiles ломаются на пробеле в пути;
DEVKITPRO задаётся в POSIX-виде и из PowerShell):
  $env:DEVKITPRO = "/opt/devkitpro"
  cmake -B build -G Ninja -DPLATFORM_SWITCH=ON -DUSE_SDL2=ON -DCMAKE_BUILD_TYPE=Release
  cmake --build build --target SplitScreenHub.nro

Не трогай catalog.db, build_db.py и make_overrides.py — с ними параллельно
работают другие сессии.
```

## E. Иконка приложения

Промт вынесен отдельно: **`PROMPT_E_ICON.md`**. Краткая версия:

```
У приложения стоит демо-иконка borealis (app/resources/icon.jpg — это копия
demo_icon.jpg из библиотеки). Нужна своя.

Требования Nintendo к иконке homebrew: JPEG ровно 256×256, без прозрачности.

Нарисуй иконку для каталога игр с совместной игрой на одном экране. Идея —
несколько силуэтов игроков перед одним экраном или четыре джойкона вокруг
экрана. Стиль плоский, читаемый в мелком размере: на главном меню консоли
иконка видна примерно 128 точками, поэтому мелкие детали и текст не нужны.
Цвета возьми контрастные, но не кислотные.

Сгенерируй SVG, сконвертируй в JPEG 256×256 и положи в app/resources/icon.jpg,
исходник — рядом как icon.svg. Проверь размер и формат:
  python -c "from PIL import Image; im=Image.open('app/resources/icon.jpg'); print(im.size, im.mode, im.format)"

Пересобирать приложение не нужно — иконка подхватывается при следующей сборке
.nro. Не трогай другие файлы: с проектом параллельно работают другие сессии.
```
