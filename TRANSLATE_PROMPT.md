# Промт для сессии перевода каталога на русский

Скопируйте всё, что ниже разделителя, в новую сессию Claude Code, открытую в
папке проекта.

## Откуда взялись ограничения длины

Замерено по `switch_font.ttf` из комплекта borealis. Приложение всегда верстает
на логическом холсте 1280×720 и масштабирует его в док-режиме, поэтому 720p и
1080p вмещают одинаковое количество текста.

| Поле | Кегль | Символов в строке (кириллица) | Влезает без прокрутки |
|---|---|---|---|
| `headline` | 19px | 111 | 2 строки ≈ 220 знаков |
| `players_note` | 17px | 125 | 2 строки ≈ 250 знаков |
| `description` | 17px | 125 | ~9 строк ≈ 1100 знаков, дальше прокрутка |

Кириллица шире латиницы примерно на 8%, и русский перевод сам по себе длиннее
оригинала на 10–15% — одна и та же фраза занимает почти на четверть больше
места. Это уже учтено в цифрах выше.

## Объём работы

`headline` — 3055 шт, 259 тыс. знаков. `players_note` — 610 шт, 25 тыс.
`description` — 3480 шт, 3.70 млн знаков, медиана 888.

Описания не обрезать. В хвостах длинных текстов лежит разбивка по числу игроков
для каждой мини-игры («Weapons Drawn (4-8 players)», «Legends of Trivia supports
1-6 players») — для каталога про совместную игру это самое ценное, а обрезка по
длине убирает это в первую очередь у Jackbox и сборников. Описание всё равно
прокручивается, так что длина ему не мешает.

Экономия достигается порядком работы: сначала короткие поля (они в 13 раз дешевле
описаний и видны в карточке первыми), потом описания от самых
многопользовательских игр к остальным — работу можно прервать в любой момент, и
переведённым окажется то, что чаще открывают.

---

Переведи на русский тексты игр в `catalog.db` (SQLite, в корне проекта).

**Куда писать.** Создай таблицу, если её нет, и работай только с ней —
`games` не трогай:

```sql
CREATE TABLE IF NOT EXISTS translations (
  nsuid TEXT PRIMARY KEY,
  headline_ru TEXT,
  players_note_ru TEXT,
  description_ru TEXT
);
```

**Этап 1 — короткие поля.** Пачками по 60:

```sql
SELECT g.nsuid, g.headline, g.players_note FROM games g
LEFT JOIN translations t USING (nsuid)
WHERE (g.headline != '' OR g.players_note != '')
  AND (t.nsuid IS NULL OR t.headline_ru IS NULL)
ORDER BY g.same_screen_max DESC, g.sort_title LIMIT 60;
```

**Этап 2 — описания.** Пачками по 15, целиком, без обрезки:

```sql
SELECT g.nsuid, g.description FROM games g
LEFT JOIN translations t USING (nsuid)
WHERE g.description != '' AND (t.nsuid IS NULL OR t.description_ru IS NULL)
ORDER BY g.same_screen_max DESC, g.sort_title LIMIT 15;
```

**Длина перевода.**

- `headline` — до 220 знаков. Медиана оригинала 77, так что почти везде это
  просто перевод как есть; ужимать до лимита нужно только длинные (у 10% игр
  оригинал больше 152 знаков).
- `players_note` — до 250 знаков, оригиналы короткие, обычно одна фраза.
- `description` — без ограничения, переводить целиком.

Если перевод не влезает в лимит, сокращай смыслом: убирай рекламные усилители
(«невероятный», «захватывающий»), а не факты. Числа игроков, названия режимов и
условия («нужны дополнительные контроллеры») не выбрасывать никогда.

**Как переводить.**

- Названия игр, издателей и имена собственные не переводить.
- Числа игроков и названия режимов сохранять точно: «(4-8 players)» →
  «(4–8 игроков)», «up to 5 players» → «до 5 игроков». Это данные, а не текст.
- Тон нейтральный, без рекламных восклицаний. Кавычки — «ёлочки», дефис в
  диапазонах — короткое тире.
- Переносы строк внутри описания сохранять: на них держится вёрстка карточки.

**Как сохранять.** После каждой пачки — `INSERT ... ON CONFLICT(nsuid) DO UPDATE`
и `COMMIT`, затем сразу следующая. Не накапливай переводы в памяти.

**Никакого лишнего вывода.** Не печатай переводы в чат и не пересказывай их.
После каждой пачки — одна строка: `N/M готово`. В конце — сколько переведено,
сколько осталось и сколько переводов пришлось сокращать под лимит.

Продолжай, пока запрос не вернёт пустой результат. Повторный запуск этого же
промта продолжит с места остановки.

**Когда перевод закончен.** В `app/source/catalog.cpp` в `SELECT_FIELDS` добавь
`LEFT JOIN translations t USING (nsuid)` и заверни три поля в `COALESCE`:
`COALESCE(t.headline_ru, g.headline)`, `COALESCE(t.players_note_ru,
g.players_note)`, `COALESCE(t.description_ru, g.description)` — тогда
непереведённые игры останутся с английским текстом, а не опустеют. Затем
`cp catalog.db app/resources/catalog.db` и пересобери приложение:

```powershell
$env:DEVKITPRO = "/opt/devkitpro"
cmake --build build --target SplitScreenHub.nro
```
