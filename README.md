# Couch co-op

Homebrew-каталог игр Nintendo Switch с мультиплеером **на одном экране**.
Отвечает на вопрос «нас четверо, во что поиграть»: фильтр «от N игроков»,
отметка того, что уже установлено на консоли, избранное и свои папки.

В каталоге **3480 игр**. У каждой известно точное число игроков на одной
консоли — не «мультиплеер есть», а «1–4».

## Откуда данные

Два публичных API, которыми пользуется сам nintendo.com:

**Algolia** (`store_game_en_us`) — каталог eShop. Ключевой фасет
`waysToPlayLabels: "Play together on one console"`.

**graph.nintendo.com** — карточка товара. Обязателен заголовок
`apollographql-client-name: ncom`, иначе сервер отвечает `Internal server error`.
Аргумент — OneOf-тип `ProductInput`, ровно один ключ: `sku` | `nsuid` | `urlKey`
(по `nsuid` доступно заметно больше товаров, чем по `sku`).

Главное поле — `numberOfPlayers`, и в нём три разных счётчика:

| Поле | Что значит |
|---|---|
| `.system` | **игроков на одной консоли** — то, что нужно |
| `.local` | локальный беспроводной на нескольких консолях |
| `.online` | онлайн |

У Mario Kart World это `system 1–4`, `local 2–8`, `online 2–24`. Европейский API
(`searching.nintendo-europe.com`) для этой задачи не годится: там единственное
поле `players_to` даёт суммарное число — у Fortnite 100, у Terraria 8 при
сплитскрине на двоих.

Около половины каталога GraphQL анонимно не отдаёт (`UNAUTHORIZED`), причём это
не связано ни с доступностью игры, ни с ценой. Такие карточки берутся со
страницы товара: она открывается обычным GET с полными браузерными заголовками
(без них 406), а в её `__NEXT_DATA__` лежит тот же объект `Product`.

## Что не попало в каталог

- **223 бандла-сборника** (nsuid `7007*`) — у них нет ни числа игроков, ни
  Title ID, ни размера
- **будущие релизы**
- **32 игры**, по которым не нашлось надёжного подтверждения мультиплеера
- **3 игры с неверной меткой eShop**: у HELLCARD кооператив только по сети,
  Double Kick Heroes одиночная, а LEGO Voyagers Friend's Pass вообще не игра,
  а пропуск для приглашения по сети

Ещё 48 игр eShop пометил `Single player`, хотя мультиплеер у них есть — среди них
все 14 Jackbox Party Pack, Rocket League, Stardew Valley и Terraria. Их числа
проверены вручную и лежат в `make_overrides.py` вместе с источником по каждой.
Там же видно, почему проверять надо именно версию для Switch: у Stardew Valley
на оригинальном Switch сплитскрин на двоих, а четверо — только в издании для
Switch 2.

Самый полезный источник оказался в самих данных: у многих игр число игроков прямо
названо в описании от издателя («a 2-player cooperative puzzle platformer»,
«up to 5 players per turns»). Это надёжнее любого агрегатора и не требует сети.

## Сборка

### Данные

```bash
python fetch_local_multiplayer.py
```

Собирает `local_multiplayer.json`. Кэширует карточки в `products_cache.json`,
так что повторный запуск доспрашивает только новинки. Чтобы переснять всё
с нуля, удалите кэш.

```bash
python make_overrides.py && python build_db.py && python download_art.py && python verify_db.py
python make_ship_db.py
```

Даёт `catalog.db` и `app/resources/art/` (3480 обложек по 256px, 53 МБ).
`verify_db.py` прогоняет по базе те же запросы, что и приложение.

### Приложение

Нужен devkitPro с `switch-curl`, `switch-mbedtls` и `switch-ffmpeg`:

```bash
pacman -S switch-curl switch-mbedtls switch-ffmpeg switch-sdl2 ninja
```

#### Видео-трейлеры

Ролики (таблица `media`, `kind='video'`, mp4/h264/aac с Cloudinary) играются
плеером собственного написания поверх `switch-ffmpeg`
(`app/source/ui/video_player.cpp`): demux/decode через
avformat/avcodec, кадр конвертируется в RGBA через `swscale` и рисуется как
nanovg-текстура, звук ресемплится `swresample` и уходит в SDL2 audio.

Предпочтительным вариантом был `libmpv` (как в NXMP и SwitchWave — с
аппаратным декодированием через Tegra NVDEC), но от него пришлось
отказаться: готового пакета `switch-mpv` в pacman нет, а сборка mpv вместе с
патченным FFmpeg из исходников под `aarch64-none-elf` по рецептам
[nxmp](https://github.com/proconsule/nxmp) и SwitchWave требует кросс-сборки
mpv+meson-тулчейна и офлайн-патчей, которые нельзя было ни получить, ни
проверить за разумное время в этом окружении. `switch-ffmpeg`, наоборот, уже
собран и лежит в pacman, поэтому выбран путь с собственным минимальным
плеером поверх него — программный декодер без NVDEC, но для 30–60-секундных
трейлеров этого достаточно.

Две особенности сборки, на которые легко потратить вечер:

- **Только Ninja.** Генератор Unix Makefiles ломается на пробеле в пути к
  проекту (`multiple target patterns` в файлах зависимостей).
- **`DEVKITPRO` задаётся в POSIX-виде** (`/opt/devkitpro`, не `C:/devkitPro`) и
  из PowerShell — переменные окружения из git-bash до msys2-cmake не доходят.

```powershell
$env:DEVKITPRO = "/opt/devkitpro"
cmake -B build -G Ninja -DPLATFORM_SWITCH=ON -DUSE_SDL2=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --target CouchCoop.nro
```

На выходе `app/build/CouchCoop.nro` (~92 МБ, в основном `catalog.db` и
`app/resources/art/` в romfs). Кладётся в `/switch/` на SD-карту.

SQLite собирается из amalgamation — порта `switch-sqlite3` не существует.
В libnx нет `fchown` и `geteuid`, на которые SQLite ссылается в таблице
системных вызовов, поэтому рядом лежит `app/lib/sqlite/nx_compat.c` с
заглушками: база открывается только на чтение, вызваны они не будут.

## Управление

| Кнопка | Действие |
|---|---|
| A | открыть игру |
| B | назад |
| X | в избранное · удалить папку |
| Y | в папку · переименовать папку |
| L / R | переключить вкладку |
| ZL / ZR | листать сетку страницами |
| − | поиск по названию |
| + | новая папка |

Фильтры: «от N игроков», жанр, «только установленные», «есть русский», поиск и
сортировка (по названию · сначала мои · по числу игроков).

Избранное и папки лежат в `sdmc:/switch/couch-coop/library.json`. Файл пишется
через временный и переименование, так что выдернутая посреди записи консоль не
уносит всю библиотеку.

## Что дальше

Разбито на пять независимых задач с готовыми промтами — см. `TASKS.md`.
Запускать можно параллельно: перевод пишет в `translations.db`, рейтинги в
`ratings.db`, а `build_db.py` подмешивает их при сборке, поэтому пересборка
каталога ничью работу не уничтожает. Приложение читает эти таблицы через
`COALESCE`, так что каталог остаётся рабочим на любой стадии.

- **Рейтинги.** Колонка `rating` в схеме есть и пустует. IGDB даёт и оценку, и
  поля `splitscreen` / `offlinecoopmax` для перекрёстной проверки наших чисел,
  но требует Client ID и Secret от Twitch developer app.
- **Оставшиеся 32 игры** — руками или тем же IGDB.
- **Иконка приложения** — сейчас стоит демо-иконка borealis.
- **Другие регионы.** Пайплайн параметризуется одной строкой: у Algolia есть
  индексы `en_ca`, `es_mx`, `fr_ca`, `pt_br`.
