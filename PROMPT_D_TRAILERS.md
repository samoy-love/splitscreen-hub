# D. Трейлеры в карточке игры

Скопируйте всё, что ниже разделителя, в новую сессию Claude Code, открытую в
папке проекта.

Задача независима от остальных: она трогает только код приложения. Не трогайте
`catalog.db`, `build_db.py`, `make_overrides.py` и `app/resources/art/` — с ними
параллельно работают другие сессии.

---

В карточке игры сейчас показываются только скриншоты. Добавь проигрывание
трейлеров.

## Что уже есть

- Адреса роликов лежат в `catalog.db`, таблица `media`, `kind='video'`. Ролики
  есть у 2139 игр из 3480 (61%), всего 2621 штука.
- Формат — mp4 с Cloudinary, h264/aac. Пример адреса:
  `https://assets.nintendo.com/video/upload/f_mp4//store/software/switch/.../Video/...`
- Метод `Catalog::videos(nsuid)` в `app/source/catalog.cpp` уже написан и
  возвращает список адресов. Сейчас он не используется — это и есть точка входа.
- Карточка собирается в `app/source/ui/game_activity.cpp`, разметка —
  `app/resources/xml/activity/game.xml`, блок `game/shots`.

## Чем проигрывать

Свой плеер не пиши. Возьми **libmpv**: ей отдаётся URL и OpenGL-контекст, а она
сама делает демукс, декод, ресемпл и синхронизацию звука. Управление — вызовы
`mpv_command` для паузы и перемотки, это несколько строк, а не плеер.

Borealis рисует через OpenGL, поэтому mpv рендерит в FBO
(`mpv_render_context_create` с `MPV_RENDER_PARAM_OPENGL_INIT_PARAMS`), а мы
показываем результат текстурой.

Под Switch libmpv собирают — посмотри рецепты:

- NXMP — `github.com/proconsule/nxmp`, там mpv 0.36 с FFmpeg и аппаратным
  декодированием H264/HEVC/VP9 через Tegra NVDEC;
- SwitchWave — тот же подход, другой набор патчей.

Пакета `switch-mpv` в pacman **нет**, libmpv придётся собирать из исходников.
`switch-ffmpeg` в pacman есть и ставится обычным `pacman -S switch-ffmpeg`.

**Запасной путь.** Если сборка libmpv упрётся в патчи или зависимости, сделай
минимальный проигрыватель поверх `switch-ffmpeg`: `av_read_frame` →
`avcodec_send_packet`/`receive_frame` → `sws_scale` в RGBA → текстура, звук
через SDL2 audio. Это заметно больше работы, поэтому выбирай его только если
libmpv действительно не собирается. И скажи об этом прямо: какой путь выбран,
на чём споткнулся первый, а не молча подмени решение.

## Что должно получиться

- Кнопка воспроизведения поверх первого скриншота — только если у игры есть
  видео. Проверяй через `Catalog::videos()`, у 39% игр роликов нет и кнопка
  появляться не должна.
- Нажатие открывает полноэкранный просмотр, выход по B.
- Пауза по A, перемотка стиком.
- Пока ролик буферизуется — видимый индикатор, а не чёрный экран.

## Чего нельзя допустить

**Интерфейс не должен замирать ни на загрузке, ни на декоде.** Посмотри, как это
уже сделано в `app/source/ui/remote_image.cpp`: связка `brls::async` для фоновой
работы и `brls::sync` для возврата в UI-поток, плюс `shared_ptr<atomic_bool>
alive`, по которому колбэк понимает, что пользователь ушёл с карточки раньше,
чем всё загрузилось. Для видео нужна та же защита: выход из активити во время
буферизации не должен ронять приложение.

**Память.** В applet-режиме homebrew получает мало RAM, и она уже занята пулом
текстур обложек. Освобождай контекст mpv при выходе из полноэкранного режима, а
не держи его на всю жизнь карточки.

**Сеть может отсутствовать.** `net::init()` в `app/source/net.cpp` при неудаче
просто пишет предупреждение и приложение продолжает работать. Видео должно вести
себя так же: нет сети — кнопка неактивна с понятной подписью, а не ошибка.

## Сборка

Ninja обязателен: генератор Unix Makefiles ломается на пробеле в пути к проекту.
`DEVKITPRO` задаётся в POSIX-виде и из PowerShell — переменные окружения из
git-bash до msys2-cmake не доходят.

```powershell
$env:DEVKITPRO = "/opt/devkitpro"
cmake -B build -G Ninja -DPLATFORM_SWITCH=ON -DUSE_SDL2=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --target CouchCoop.nro
```

Проверить работу на железе без консоли нельзя — это честно скажи в отчёте.
Проверяемо здесь только то, что проект собирается и `.nro` получается.

Когда закончишь, обнови в `README.md` раздел «Что дальше»: трейлеры оттуда
убрать, а в разделе про сборку описать, откуда берётся libmpv.
